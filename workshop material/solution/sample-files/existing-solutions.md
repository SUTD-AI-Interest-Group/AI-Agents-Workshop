# Existing approaches we've seen (starting notes — verify with web search!)

- Telegram / WhatsApp "looking for team" groups: free, everyone's already there, but noisy.
- Spreadsheet sign-up sheets run by TAs: simple, but stale after week 1.
- Hackathon team-matching boards (e.g. Devpost-style): skills tags, aimed at one-off events.
- Some universities use survey-based algorithmic team formation tools (e.g. CATME Team-Maker).
